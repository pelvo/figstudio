## P3 — Desktop app (`apps/figstudio`)
- [x] Visible canvas layers are accessibility nodes (name, kind, size, place, selected); pressing one selects it
- [x] Properties rows read as one "key: value" item
- [x] Toasts and errors are live regions; a file being opened is a named progress indicator
- [x] Every control has a stable automation id (AXIdentifier / AutomationId)
- [x] Press by accessibility element checked in the macOS bundle (Zoom in, a canvas layer)
- [ ] Fill and stroke rows in Properties read as one item

## Progress

### 2026-10-28T083503Z a11y-agents
- What changed and how it was checked: `canvas_a11y.rs` lists the visible layers under the
  canvas, at most 400 per frame from at most 20 000 visited, and only while AccessKit is on. The
  canvas is a Group (macOS does not look inside an image). Properties rows are hidden key plus
  "key: value" value. `a11y::announce` and `a11y::progress` handle live regions. Automation ids
  cover every control; recent files use a hash of the path. Two toasts born in the same frame
  no longer share an Area id. Each change has a test in `ui_a11y_tests.rs` that failed without
  it. `FIGSTUDIO_TOOLCHAIN=1.99.0 scripts/check.sh` passed. In the macOS bundle the system
  tree showed the layers, ids and rows, and pressing Zoom in and a canvas layer by element
  worked.

### 2026-10-29T004348Z a11y-agents
