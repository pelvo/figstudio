## P5 — Editing (`crates/fig`, `apps/figstudio`, `apps/figstudio-mcp`, `apps/figstudio-cli`)
- [x] Non-destructive `Txn` / `History` engine with exact `state_id` tracking across Undo/Redo
- [x] Safe `save_copy_checked` (`.fig` required, rejects `..` traversal & folder escape, refuses to overwrite source, requires `overwrite: true` for existing targets via atomic `hard_link`)
- [x] Parametric geometry, ancestor-scoped Auto-Layout solver, and crisp rendering of newly created `TEXT` layers (`lineHeight: PERCENT`)
- [x] Two-way Figma HTML clipboard (`html-escape` entity decoding) + `egui::Event::Paste` shortcut & plain-text fallback
- [x] Modularized `crates/fig/src/edit/ops/` and `apps/figstudio/src/editor/` (<460 lines per file) with unified `TabMutation` dispatcher
- [x] Round-2 review fixes: batch guid allocation for duplicate, save-copy confinement/identity/fallback, unsaved-edits prompt on close and quit, clipboard image bytes and reused-master mapping, iterative layout/resize, transformed canvas drags, drawable created LINEs
