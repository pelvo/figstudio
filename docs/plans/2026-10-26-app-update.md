## Progress

### 2026-10-26T054146Z update-check
- 2026-10-26 — Desktop update check (Settings → About, `update.rs`): a "Check at start" switch (off by default, saved in `Prefs`; older preferences load with it off) and a Check now button ask GitHub for its releases and compare with semver. On macOS arm64, a `.app` not installed by Homebrew gets Install: it downloads the release zip and `SHA256SUMS`, checks the SHA-256, unpacks with `ditto`, checks `codesign --verify --deep --strict` and the bundle's version, then swaps it in by rename (old bundle restored if the second rename fails); Restart now relaunches after this process exits. Homebrew installs get the `brew upgrade --cask` command; other builds get the release page. About's privacy line now names the update check. Crates: reqwest (blocking, rustls; already in the workspace) and semver. Tests: 7 in `update.rs` plus `the_update_check_is_off_until_turned_on_and_is_remembered`; four mutations (no rollback, `<` for `<=`, no `*` in SHA256SUMS, switch on by default) each failed a test. A throwaway live test installed the real v0.2.0 zip over a dummy bundle (21 MB, checksum, ditto, codesign, plutil, swap, clean-up) and a mismatched checksum changed nothing. Not verified: Restart now on a real installed app, an install into a folder the user cannot write, Gatekeeper on the swapped app, the About layout on screen.
