- 2026-10-22: Cloud relay reconnect in a background tab. Review of the change above found that noticing a closed relay, the retry timer, the `ready` greeting and the keepalive still ran only on eframe's throttled timer, so a hidden tab could stay unreachable for up to a minute after a drop. The browser host's state now sits behind a shared cell (`McpHost` wraps `Host`), and the socket's callbacks, plus timers set from them, run a pump between frames (`mcp_web_pump.rs`): it applies the connection's own events, retries on the backoff plan, greets a new connection with `ready` from the tabs the last frame saw, starts calls that waited for the welcome, and pings. Work that needs the tabs (uploads, reveals, the local bridge) still waits for a frame. New e2e `a hidden tab reconnects a dropped relay without waiting for a frame` closes the relay socket while eframe's timer is held to 60 s and expects calls answered again within 15 s; it failed at the previous commit and passes now. A follow-up review found that a loss the keepalive detects (no `pong`, so no `close`) still left its retry to a frame; `relay_lost` now sets the retry's wake itself, and e2e `a hidden tab retries a relay whose keepalive went unanswered` failed before that and passes now. Each retry wait now adds up to 25% of its delay at random (`JITTER` in `mcp_backoff.rs`), so the tabs one Worker deploy dropped do not all retry in step; its unit test failed with the spread removed. A later review found that a call started from the socket callback no longer asked for a frame, so in a visible but idle tab a `reveal_node` waited out its 2 s ack; the socket now wakes the host for a started call too, and the tools e2e calls `reveal_node` after 2 s idle (failed before, passes now). Off the relay, the calls' tab view is now cleared each frame, so it no longer keeps closed documents alive. The other relay specs are unchanged (8 of 9 pass locally; the join spec still stops at its dialog). Not verified: real Chrome intensive throttling, Safari and Firefox, a real Cloudflare deploy.
